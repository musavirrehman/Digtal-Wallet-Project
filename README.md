# NixCash - Digital Wallet Web Application

NixCash is a full-stack digital wallet web application built with **PHP, MySQL, Bootstrap 5, HTML, CSS, and JavaScript**. It provides a modern fintech-style platform where users can manage their digital wallet, transfer money, track transactions, create savings goals, split bills, use virtual cards, pay utility bills, and recharge mobile accounts.

### Key Features

* User registration and secure login
* Digital wallet and balance management
* Add money, withdraw money, and transfer money
* Transaction history and financial summaries
* Savings goals with progress tracking
* Split bills between registered users
* Virtual card generation and management
* Demo merchant payments through virtual cards
* Electricity, gas, and internet bill payments
* Mobile recharge
* User profile management
* PDF transaction statements
* Notifications system
* Admin dashboard for managing users, transactions, cards, loans, goals, and split bills
* Database transactions using PDO for reliable money transfers

### Technologies Used

* **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
* **Backend:** PHP 8+
* **Database:** MySQL / MariaDB
* **Database Access:** PDO
* **Server:** Apache / XAMPP
* **PDF Generation:** FPDF

### Purpose

This project was developed as an educational fintech application to demonstrate practical implementation of **web development, database management, authentication, financial transaction handling, CRUD operations, and admin management** in a real-world style digital wallet system.

> **Note:** NixCash is an educational/demo project and is not intended for handling real financial transactions. Production deployment would require additional security measures, HTTPS, CSRF protection, rate limiting, secure payment gateways, and other financial compliance requirements.
